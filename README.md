# XDK Petits Pas — téléchargements

**Petits Pas** réunit six petits jeux, faits maison et gratuits, pour les enfants de 4 à 7 ans avec un
**syndrome 22q11**. Une voix française guide l'enfant : pas besoin de savoir lire. Il n'y a jamais de « perdu » :
une erreur, c'est juste une nouvelle chance.

## Il faut le code d'accès

Les fichiers de ce dépôt sont **chiffrés** : sans le code d'accès donné aux familles par la TEAM XDK, ils ne
s'ouvrent pas. Le même code ouvre tous les jeux pour enfants (Petits Pas, Tchac !).

- 💻 **PC (Windows 10 et 11)** : installe [XDK Hub](https://github.com/XDTEAMDev/XDK-Hub-releases/releases/latest),
  va dans **Jeux pour enfants**, choisis **Petits Pas** et tape le code. Le hub s'en souvient et garde le jeu à jour.
- 📱 **Android** et 🌐 **navigateur** : ouvre **https://xdteamdev.github.io/petits-pas/** et tape le code.
  Tu peux y jouer tout de suite ou télécharger l'appli Android (`XDKPetitsPas.apk`).

## Les six jeux

- 🔤 **Les syllabes** : coller deux lettres (D + A = DA), jouer avec les lettres, retrouver la syllabe entendue.
- 🔊 **Loto des sons** : écouter un bruit (vache, pompiers, cloche…) et trouver l'image.
- 🚀 **La fusée** : tenir un long « aaah » pour envoyer la fusée sur la lune, sans crier.
- 🌞 **Ma journée** : les étapes de la journée en images (« Maintenant / Après »), réglables par les parents.
- 😊 **Les émotions** : reconnaître des visages, deviner l'émotion dans une petite histoire, dire comment on se sent.
- 🧘 **Coin calme** : respirer avec une bulle, avec des vagues, de la pluie ou une petite musique.

Marche **sans Internet** une fois installé. Rien n'est envoyé : les réglages, les étoiles et la journée restent sur
l'appareil. Le micro sert seulement à faire monter la fusée : rien n'est enregistré.

Ces jeux complètent le travail de l'orthophoniste, ils ne le remplacent pas.
